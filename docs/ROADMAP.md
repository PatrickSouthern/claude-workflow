# Roadmap

The intended order of work, grouped into phases. It's a forecast, not a commitment: each task still
gets its own plan and approval. Tasks get a number only when they are planned. Follow-ups that aren't
scheduled yet live in [tasks/BACKLOG.md](tasks/BACKLOG.md).

Every phase ends with a process review (`workflow:review-process`): did the process changes in
[PROCESS-LOG.md](PROCESS-LOG.md) work, what can be pruned, and what should change in the workflow
plugin.
