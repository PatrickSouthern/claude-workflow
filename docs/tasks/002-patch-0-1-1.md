## Decisions
- **2026-10-13 — Approved by the user** ("go ahead and patch") with the scope agreed earlier: B1

- **2026-10-13 — Wording follows the docs' protected-paths table.** Project `.claude/` is protected:
  Manual (`default`) and `acceptEdits` prompt; `auto` routes the write to the classifier (it may go
  ahead without asking, as the user saw); `dontAsk` denies; `bypassPermissions` allows. Allow rules
  don't pre-approve protected paths. Source:
